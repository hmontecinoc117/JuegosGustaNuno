# Style Bible

## Global Art Direction

Cartoon premium infantil mobile game, Disney and Dreamworks inspired, warm and friendly, cute characters, big expressive eyes, soft rounded shapes, lively soft colors, polished mobile casual game finish, soft shading, clean silhouette, centered composition, readable at small sizes, prepared for Godot 4.x Android landscape.

## Character Style

- Cute and friendly.
- Big expressive eyes.
- Rounded body shapes.
- Soft warm lighting.
- Clean silhouette.
- Premium cartoon render.
- Child safe, joyful, playful.

## UI Style

- Glossy premium UI.
- Rounded corners.
- Soft shadows.
- Bright but soft color palette.
- Chunky mobile game buttons.
- Clear centered composition.
- No text baked into images.
- No logos.

## Background Style

- Horizontal Android landscape composition.
- Cartoon outdoor world.
- Soft clouds, gentle hills, playful shapes.
- Clear open center area for UI.
- Premium mobile game quality.

## Asset Rules

- PNG output.
- Transparent background when the manifest says transparent.
- No text.
- No watermark.
- No collage.
- No sprite sheet.
- No multiple unrelated objects.
- No cropped subject.
- No signature.
- No logo.

## Global Negative Prompt

text, watermark, logo, signature, blurry, low quality, distorted, extra limbs, bad anatomy, cropped, out of frame, collage, sprite sheet, multiple objects, duplicate character
